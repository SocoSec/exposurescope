2. CONCURRENCY: TAIL, NOT SUM
------------------------------------------------------------------------------
   aggregate p50                       103 ms
   aggregate p95                       544 ms
   slowest provider's own p50          101 ms
   sum of all providers' p50           282 ms   <- the sequential cost

   The aggregate tracks the SLOWEST source (101 ms), not the sum
   (282 ms). Concurrent dispatch therefore saves roughly
   179 ms, and adding a sixth source costs nothing unless it is
   slower than the current tail. This is the claim section 6.2 makes.
