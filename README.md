ExposureScope is a research prototype designed to measure and analyze personal data exposure. It allows users to safely check their digital footprint through a combination of secure password checks (using k-anonymity via the Have I Been Pwned API), email breach lookups, and AI-driven attribute inference (powered by Anthropic models). The tool calculates a heuristic "exposure index" to help quantify data risk and serves as a foundational scaffold for ongoing research into uncertainty-aware privacy scoring.
